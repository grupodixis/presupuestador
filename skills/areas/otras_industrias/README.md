# Área: Otras industrias

## Objetivo

Usar esta carpeta como incubadora para nuevas industrias que interese atacar: mantenimiento industrial, mobiliario técnico, rotulación, automatismos, energía, construcción ligera, maquinaria, obra civil u otras líneas de negocio.

## Cómo registrar una industria nueva

Crear una sección con:

- Nombre de industria.
- Cliente objetivo.
- Productos o servicios presupuestables.
- Datos mínimos necesarios.
- Partidas habituales.
- Riesgos principales.
- Proveedores o fuentes de coste.
- Primeros ejemplos reales.
- Estado: exploración, piloto, activa o descartada.

## Criterio de promoción

Cuando una industria tenga al menos 5 presupuestos reales, proveedores identificados y una composición repetible, crear una carpeta propia en `skills/areas/` y una o más composiciones en `productos/composiciones/`.

## Aprendizaje del área

Guardar correcciones y criterios en `skills/aprendizaje/aprendizaje_otras_industrias.md` hasta que exista un área propia.
