# Área: Instalaciones eléctricas

## Cuándo usarla

Usar esta área cuando el presupuesto incluya baja tensión, cuadros eléctricos, líneas, mecanismos, iluminación, tomas, canalizaciones, legalizaciones, automatización, domótica o apoyos eléctricos a instalaciones solares/clima.

## Criterios base

- Confirmar si requiere instalador autorizado, boletín, memoria o proyecto.
- Separar materiales, mano de obra, canalizaciones, mecanismos/equipos, pruebas y legalización.
- Preguntar por potencia, número de puntos, planos, reforma/obra nueva y calidad de mecanismos.
- En reformas, incluir rozas, tapado, reposición y coordinación con otros gremios si aplica.
