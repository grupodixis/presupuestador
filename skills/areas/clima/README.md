# Área: Clima

## Cuándo usarla

Usar esta área para climatización, aire acondicionado, ventilación, extracción, conductos, unidades interiores/exteriores, aerotermia, drenajes, refrigerante, puesta en marcha y mantenimiento.

## Criterios base

- Confirmar potencia, estancia, ubicación de unidad exterior, distancia frigorífica, drenaje y acceso.
- Separar equipo, línea frigorífica, canalización, soporte, electricidad auxiliar, drenaje, mano de obra y puesta en marcha.
- Revisar RITE y necesidad de instalador habilitado según alcance.
- En Menorca, valorar corrosión en soportes y tornillería exterior.
