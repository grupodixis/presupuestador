# Área: Fontanería

## Cuándo usarla

Usar esta área para agua fría, agua caliente sanitaria, saneamiento, desagües, baños, cocinas, griferías, sanitarios, bombas, acumuladores y pruebas de estanqueidad.

## Sectores previstos

| Sector | Estado | Base actual | Falta desarrollar |
|---|---|---|---|
| Baños | preparado | `skill_instalaciones.md`, `instalacion_fontaneria.yaml` | puntos, sanitarios, griferías, rozas, pruebas |
| Cocinas | preparado | composición genérica | fregadero, lavavajillas, termo, tomas y desagües |
| Saneamiento | pendiente | composición genérica | pendientes, arquetas, ventilación, diámetro, pruebas |
| ACS | pendiente | composición genérica | termo, acumulador, recirculación, aislamiento |
| Bombeo | pendiente | sin skill propia | bombas, grupos presión, válvulas, puesta en marcha |

## Criterios base

- Preguntar siempre por número de puntos, distancia, material de tubería, accesibilidad y si hay obra civil.
- Separar tubería, accesorios, sanitarios/equipos, mano de obra, pruebas y reposiciones.
- Incluir prueba de presión/estanqueidad cuando proceda.
- Si interviene albañilería, indicar si está incluida o excluida.
