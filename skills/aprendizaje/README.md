# Aprendizaje del presupuestador

Esta carpeta guarda el conocimiento que nace del uso real de la app: cambios manuales, correcciones con IA, partidas eliminadas, precios ajustados y criterios que el usuario quiere conservar.

## Promoción del aprendizaje

1. **Observado**: se guarda automáticamente después de una corrección real.
2. **Validado**: un usuario confirma que el criterio debe repetirse.
3. **Consolidado**: se integra en la skill, composición o coste correspondiente.
4. **Descartado**: se conserva solo como antecedente si fue un caso excepcional.
