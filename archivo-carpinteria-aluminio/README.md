# Archivo de carpinteria de aluminio

Esta carpeta conserva la base de conocimiento retirada del presupuestador principal para crear una app separada de carpinteria de aluminio.

Contenido archivado:

- Skills de aluminio, ALUFAC, CORTIZO y mallorquinas.
- Composiciones y requisitos YAML de ventanas, cerramientos, ALUFAC, CORTIZO y persianas mallorquinas.
- Reglas tecnicas CORTIZO.
- Historicos y costes especificos de aluminio.

La app principal no carga esta carpeta porque esta fuera de `skills/`, `productos/` y `presupuestacion/`.
